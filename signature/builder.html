Installing

Gmail: Settings, See all settings, Signature. Outlook web: Settings, Mail, Compose and reply. Outlook desktop: File, Options, Mail, Signatures. Apple Mail: Settings, Signatures, then untick Always match my default message font. Use Copy signature and paste straight in; Copy HTML is for anyone pasting into a system that wants markup.

Why the type is not Switzer

Mail clients do not load webfonts. Outlook renders through Word, and Gmail strips the <style> block that @font-face needs, including when you paste into its own signature box. Type set in Switzer therefore falls back silently and loses its metrics, which is what the previous signature was doing. Here the brand line is drawn as an image in real Switzer, and the rest uses the stack the site itself falls back to. Try the site fonts adds the webfont for the minority of clients that honour it, and changes nothing for everyone else.
